# LCROSSY Homebrew Tap

KeepClam 的 Homebrew 安装渠道。

```sh
brew install --cask LCROSSY/tap/keepclam
```

更新：`brew update` 后运行 `brew upgrade --cask keepclam`。
卸载：先关闭「登录时启动」、结束合盖运行并退出应用，再运行 `brew uninstall --cask keepclam`。

当前提供 v0.1.0 预览版，要求 macOS 13+。应用尚未经过 Apple 公证。

[项目说明与授权移除方法](https://github.com/LCROSSY/KeepClam)

本次分发版本统一为 v0.1.0。已安装过旧包的用户请先结束会话、退出应用，然后运行 `brew update` 和 `brew reinstall --cask LCROSSY/tap/keepclam`。
